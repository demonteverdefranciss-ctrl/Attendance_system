# Pico facefinder cascade

`facefinder` is the MIT-licensed frontal-face cascade from
[nenadmarkus/pico](https://github.com/nenadmarkus/pico)
(commit `c2e81f9d23cc11d1a612fd21e4f9de0921a5d0d9`).

Used by PHP and browser enrollment-photo checks so parents cannot submit
non-face or full-body pictures when Python OpenCV is not available.
